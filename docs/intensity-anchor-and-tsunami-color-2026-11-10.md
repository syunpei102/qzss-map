# 震度アイコンの位置と津波パネルの配色

2026年11月10日（火），Dia（macOS）とSafari（iPhone）で，ズームに伴い震度アイコンの位置が動くとの報告．当初の「大きさが変わる」という表現をサイズ測定だけで確認してしまい，位置の異常を見落とした．ユーザー画像ではアイコンが県から離れて海上へ押し出されていた．

## 原因と修正

- 震度アイコンは34px固定でも，重なり回避で画面上の位置を押しのけ，その位置を緯度経度へ変換してマーカーへ保存していた．ズーム中は押しのけ量まで拡大縮小し，zoomendで再計算すると位置が跳ねた．修正前の隔離ブラウザ検証では基準座標からの最大ずれが独自描画で約241px，MapLibreで約464pxとなった．
- 押しのけによる座標変更を廃止し，都道府県の基準座標へ固定する．同じ県の最新情報だけを表示する処理と，フォーカス対象の絞り込みは維持する．縮小時にもアイコンを他の場所へ移動しないため，近い県同士ではアイコンが重なることがある．
- 津波パネルは見出しが津波色，左帯が訓練などの深刻度色という別経路だった．見出し背景と左帯が同じCSSカスタムプロパティを参照する方式へ変更し，本番・訓練・手動テストで同色にする．統合カードでも最も強い津波警報の見出しと色を保持する．

## 検証

Node 143件，Python 13件，release:check，diffチェックが成功．近接する複数県と震源が重なる条件で，ズームに関係なく同じ基準座標が使われる回帰テストを追加した．津波警報・大津波警報・その他・既定色，本番・訓練・手動テスト・統合カードの色共有も確認する．ブラウザ上ではマーカーの描画完了後の中心と基準座標の投影位置を比較し，ズーム中の全フレームで検証する．詳細なブラウザ結果と公開・OTAの適用状態はObsidianの運用記録へ残す．
