# パネルを考慮した地図カメラ調整

2026年11月10日（火）．ユーザーがローカルで確認したズーム処理をv1.12.6として公開する．ローカル再生用の計測・レイテンシ画面の変更は今回の公開へ含めない．

従来のPC向け固定余白と画面幅35％の上限を廃止し，地図コンテナと情報パネルの実際の矩形から，パネルを除いた右・下・左・上で最も広い領域を選んで対象地域を収める．パネルの内容・大きさ，ウィンドウの大きさが変わった場合にもカメラを再計算する．

Node 148件・Python 13件・release:check・diffチェック成功．千島列島EEWのローカル検証では1366×768・900×600・800×480・390×844と独自描画／MapLibreの8条件でパネルと対象地域の投影矩形が交差しないことを確認する．公開の確認は本番への試験電文再送を行わず，配布ファイル・表示・接続状態を確認する．Cloud Runの公開リビジョン，環境変数と訓練OFF設定の保持，OTAの配信・実機適用状態はObsidianへ記録する．
