# 震源・震度・津波マーカーの期限とサイズ

検証日：2026年11月9日（月）．対象バージョン：1.12.3．

## 原因と修正

- 既存のEEW修正は予測範囲の5分失効のみが対象で，震源の寿命は統合カードのタイマーに依存していた．津波を統合すると長いTTLが震源・震度へも適用された．地震の地理表示に独立した絶対期限を設け，期限時に震源ソース・震度バッジ・塗りを除去する．津波のカードと沿岸線は維持する．
- 統合のたびに過去のTTLと今回の残り時間の最大値を再スタートしていた．絶対期限の最大値でタイマーを予約する方式へ変更した．残り0を無期限と解釈する条件も修正した．地図データの読込待ちも通報の経過時間へ加算する．
- 震度バッジの倍率はズームに連動していた．画面上のサイズを固定し，重なり回避も同じ固定半径を使う．津波沿岸線も8pxに固定する．沿岸線の地理的な形状は地図と一緒に拡大縮小する．
- 震源のicon-sizeは既に固定値だったが，独自描画では画像のpixelRatioを無視し，MapLibreの2倍で表示していた．pixelRatioを反映し，両描画方式で画像56pxを画面上28pxとして描く．MapLibreの画面向き指定も明示する．

## 検証

- Node 133件，Python 13件，release:check，git diff --checkが成功．Nodeに期限境界・津波統合・絶対期限・画像pixelRatioと画面密度の回帰確認を追加した．既存レイテンシ統合テストの浮動小数点完全一致を許容誤差へ変更した．本体のレイテンシ処理は変更していない．
- ChromiumでWeb／キオスク，独自描画／MapLibreの4通りを確認．各方式でズーム3・6・10の震源画像を取得し，赤い十字部分が全12枚で18×18pxと一致した．震度バッジのDOM寸法も各ズームで一致した．
- 同じ地震の震度速報へ津波を統合し，地震側の残り1.5秒を実際に待機した．4通りすべてで期限前は震源あり，期限後は震源ソース0件・震度バッジ0件・都道府県0件となり，津波1件とカード1件は残った．JavaScript例外0件．
- 本番への試験通報送信は行っていない．受信機の適用状態はObsidianの運用記録でCloud Runとは分けて記載する．
